Как устроен баланс

Ротация предложений

У одного NPC показывается только один вариант каждого пака. Набор меняется по игровым дням и отличается у разных квестодателей.

Общий лимит

Нельзя держать больше пяти заданий этого набора одновременно. Штурмы и оборона ограничены одной активной операцией.

Общий кулдаун

Сдача задания временно закрывает весь тематический пак, а не только конкретный JSON-квест. Состояние хранится в сохранении.
