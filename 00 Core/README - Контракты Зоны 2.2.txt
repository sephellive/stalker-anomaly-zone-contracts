КОНТРАКТЫ ЗОНЫ / ZONE CONTRACTS 2.2 — WTF 4.2.3

РУССКИЙ
--------------------

Назначение
--------------------
Модульный набор из 24 повторяемых заданий для существующего прохождения.
Новая игра не требуется. Старые идентификаторы восьми первоначальных боевых
контрактов сохранены, поэтому уже активные задания не удаляются.

Паки
--------------------
1. Патрульные контракты — 8 динамических боевых заданий с уменьшенной оплатой.
2. Штурмовые операции — 4 живые базы, зачистка гарнизона и захват документов.
3. Оборона рубежей — 3 тяжёлых сценария по шесть групп или волн.
4. Научные экспедиции — 5 заданий про лаборатории, артефакты и исследования.
5. Полевая работа — 4 задания на разведку, снабжение, поиск и охоту.

Защита от фарма
--------------------
- Не более пяти активных заданий этого набора суммарно.
- Патруль / наука / поле: не более двух активных заданий каждого пака.
- Штурм / оборона: только одна активная операция каждого пака.
- После сдачи включается общий кулдаун пака от 8 часов до 3 игровых дней.
- Один NPC предлагает только один ротируемый вариант каждого пака.
- У каждого конкретного задания есть дополнительный повторный таймер.

Штурмы баз
--------------------
Штурм учитывает только те вражеские отряды, которые реально занимают базу в
момент принятия задания. Сюжетные NPC не создаются и не заменяются. Задание
появится снова только после окончания кулдауна и восстановления подходящего
гарнизона симуляцией. Помимо зачистки требуется подобрать уникально созданный
экземпляр документов. При отказе документы удаляются.

Совместимость
--------------------
- Требуется Weird Tasks Framework 4.2.3.
- Рассчитано на текущую SEPHELLIVE Custom Base / GAMMA.
- Работает на существующих сохранениях.
- Не изменяет оригинальные файлы WTF, New Tasks или GAMMA.
- Созданные для обороны отряды удаляются при отказе от задания.
- Оборона начинается после прибытия игрока на рубеж и предупреждения квестодателя.
- В прорыве «Монолита» есть экзоскелетчики и два расчёта РПГ.
- Уже активная старая версия задания сохраняется до сдачи или отмены.

Баланс FOMOD
--------------------
«Суровая экономика» (рекомендуется): денежная часть ×0,75.
«Умеренная экономика»: денежная часть ×1,00.
Глобальные коэффициенты сложности экономики и WTF применяются дополнительно.

ENGLISH
--------------------

Purpose
--------------------
This is a modular set of 24 repeatable quests for an existing playthrough.
A new game is not required. The identifiers of the eight original combat
contracts are preserved, so active quests are not removed by the update.

Packs
--------------------
1. Patrol Contracts — 8 dynamic combat quests with reduced payment.
2. Assault Operations — 4 active bases, garrison cleanup and document recovery.
3. Defend the Line — 3 heavy scenarios with six groups or waves each.
4. Scientific Expeditions — 5 quests involving laboratories, artifacts and research.
5. Field Work — 4 quests involving scouting, supplies, recovery and hunting.

Anti-farming rules
--------------------
- No more than five active quests from this addon in total.
- Patrol / science / field work: no more than two active quests from each pack.
- Assault / defense: only one active operation from each pack.
- Completing a quest starts a shared pack cooldown from 8 hours to 3 in-game days.
- Each NPC offers only one rotating option from each pack.
- Every individual quest also has its own repeat timer.

Base assaults
--------------------
An assault tracks only the hostile squads actually occupying the base when the
quest is accepted. Story NPCs are not spawned or replaced. The quest can appear
again only after its cooldown expires and the simulation repopulates a suitable
garrison. Clearing the base is not enough: the uniquely spawned documents must
also be recovered. Those documents are removed when the quest is abandoned.

Compatibility
--------------------
- Requires Weird Tasks Framework 4.2.3.
- Designed for the current SEPHELLIVE Custom Base / GAMMA.
- Works with existing saves.
- Does not overwrite original WTF, New Tasks or GAMMA files.
- Squads spawned for defense quests are removed when the quest is abandoned.
- A defense starts after the player reaches the line and receives the quest giver's warning.
- The Monolith breakthrough includes exoskeleton troops and two RPG teams.
- An already active old quest version remains cached until completion or cancellation.

FOMOD balance
--------------------
"Harsh economy" (recommended): monetary rewards ×0.75.
"Moderate economy": monetary rewards ×1.00.
Global economy difficulty and WTF multipliers are applied in addition.

Documentation
--------------------
Open docs\index.html in a browser. The page works completely offline and
contains Russian and English interfaces.
