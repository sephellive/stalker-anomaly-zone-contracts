КОНТРАКТЫ ЗОНЫ 2.0 — WTF 4.2.3

Назначение
==========
Модульный набор из 24 повторяемых заданий для существующего прохождения.
Новая игра не требуется. Старые идентификаторы восьми первоначальных боевых
контрактов сохранены, поэтому уже активные задания не удаляются.

Паки
====
1. Патрульные контракты — 8 динамических боевых заданий с уменьшенной оплатой.
2. Штурмовые операции — 4 живые базы, зачистка гарнизона и захват документов.
3. Оборона рубежей — 3 сценария защиты Ростка.
4. Научные экспедиции — 5 заданий про лаборатории, артефакты и исследования.
5. Полевая работа — 4 задания на разведку, снабжение, поиск и охоту.

Защита от фарма
===============
- Не более пяти активных заданий этого набора суммарно.
- Патруль / наука / поле: не более двух активных заданий каждого пака.
- Штурм / оборона: только одна активная операция каждого пака.
- После сдачи включается общий кулдаун пака от 8 часов до 3 игровых дней.
- Один NPC предлагает только один ротируемый вариант каждого пака.
- У каждого конкретного задания есть дополнительный повторный таймер.

Штурмы баз
==========
Штурм учитывает только те вражеские отряды, которые реально занимают базу в
момент принятия задания. Сюжетные NPC не создаются и не заменяются. Задание
появится снова только после окончания кулдауна и восстановления подходящего
гарнизона симуляцией. Помимо зачистки требуется подобрать уникально созданный
экземпляр документов. При отказе документы удаляются.

Совместимость
=============
- Требуется Weird Tasks Framework 4.2.3.
- Рассчитано на текущую SEPHELLIVE Custom Base / GAMMA.
- Работает на существующих сохранениях.
- Не изменяет оригинальные файлы WTF, New Tasks или GAMMA.
- Созданные для обороны отряды удаляются при отказе от задания.

Баланс FOMOD
============
«Суровая экономика» (рекомендуется): денежная часть ×0,75.
«Умеренная экономика»: денежная часть ×1,00.
Глобальные коэффициенты сложности экономики и WTF применяются дополнительно.
